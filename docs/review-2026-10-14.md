# Translator review — 2026-10-14

This bounded review covered the translator's GUI, provider requests, settings and cache persistence, batch retries, cancellation and resume checkpoints, Minecraft language/task/book parsing, format preservation, CLI, dependencies, and packaging. Unrelated projects and the bundled browser game were outside scope.

## Repairs

| Area | Reproduced problem and resulting behavior |
| --- | --- |
| MiMo | Retired v2.5 IDs remained in the UI and saved configuration. Direct MiMo requests and persisted settings now migrate Pro to `mimo-v2.6-pro` and the standard tier to `mimo-v2.6-flash`, preserving custom endpoints. Malformed saved model values use a safe preset. |
| API responses | Null content, Anthropic/Gemini truncation flags, hard-coded retry delays, and credential-bearing error details were handled incorrectly. Responses now fail safely or split for recovery, honor Retry-After, and redact known request keys. Cancellation stops subsequent split requests. |
| Batch and lookup | Malformed backup responses could discard valid primary translations; unusable saved values could suppress work or hide valid memory hits. Accepted rows and cache/memory hit predicates now match output validation, including format tokens and length. |
| Settings | Windows silently fell back to reversible Base64 when pywin32 was missing. Native DPAPI now protects keys without another dependency and fails closed. Atomic JSON replacement preserves previous settings on write failure; malformed documents are handled safely. Legacy Base64 can still be read. |
| Legacy persistence | Unrestricted pickle/shelve reads could execute serialized objects. A plain-data loader blocks imported callables and cached extension bypasses while preserving ordinary string/dict cache protocols 0–5. |
| SQLite | Replacement writes could erase committed data, report false success, or discard pending rows on commit failure. Transactions preserve old data and pending retry state. Temporary stores are closed. |
| Formats | JSON/Markdown cancellation dropped remaining content; Markdown code fences and YAML scalar syntax reached translation incorrectly; SNBT field context was lost across lines/lists. Structure and technical fields are now preserved, quoted YAML scalars share decoded extraction/translation text, and translation misses remain byte-for-byte unchanged. |
| Files | JSON comment cleanup joined distinct tokens; locale fallback overwrote `false`/`0`; truncated class constants remained patchable; JAR comments were discarded. These inputs now retain their intended values or are rejected safely. |
| CLI | Failures/cancellation returned exit 0, filters left an unfiltered translation snapshot, some file targets escaped limits, and engine overrides wrote the wrong fields. Exit status, cleanup, target limits, and selected-engine key/model/endpoint overrides now match actual execution. |

## Validation

- Base commit: `c15531f20d42ba31da841772275ec999d933e5e6`; clean fresh checkout.
- Corrected baseline: **319 passed, 13 failed, 3 subtests passed**. Default sandbox temp paths caused an earlier invalid run; the recorded baseline used an explicitly writable temp directory.
- Final local suite: **459 passed, 3 subtests passed**, Python 3.12 on Windows.
- Added review regressions: **126 tests**, independently rerun by a fresh reviewer. That review also found and verified the malformed MiMo model, YAML scalar, and overlong-cache corrections.
- Syntax compilation, `pip check`, and `git diff --check`: passed.
- PyInstaller builds the checked-in Windows spec, including OpenCC dictionaries; no dependency versions were changed.
- Actual source GUI construction, provider widgets, MiMo tier migration, and shutdown: passed.
- Synthetic Minecraft 1.20.1 manifest plus loose language file: CLI scan/dry-run passed with network requests forbidden.
- Added GitHub Actions checks for Windows/Linux tests and Windows packaging.

Some pre-existing tests assumed a removed Bing-first policy or rejected a batch that the documented split-retry path can recover. They were changed to exercise the current GTX/MyMemory policy, explicitly selected providers, and strict parser validation rather than restoring retired behavior.

## MiMo compatibility evidence

The [Chinese retirement announcement](https://mimo.mi.com/docs/zh-CN/updates/deprecate) specifies automatic replacement on 2026-10-14 18:00 UTC+08 and invalid old IDs on 2026-10-21 10:00 UTC+08. The [model list](https://mimo.mi.com/docs/zh-CN/quick-start/summary/model) documents a 1M context and 128K maximum output. The [thinking guide](https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/text-generation/deep-thinking) confirms the existing `/v1` endpoint and `thinking.type=disabled` option. Requests retain the explicit `max_completion_tokens=4096` bound and existing nonthinking temperature settings rather than adopting the much larger provider default.

## Limits

No private settings or real keys were inspected, no user translation content was submitted, and no paid API quota was spent. Live-provider quality/latency and Minecraft gameplay were not tested. Windows packaging success and source GUI smoke checks do not establish every packaged runtime interaction. Linux execution is covered by the new remote CI, not by this Windows workstation. No Release or merge is part of this change; a draft PR is the integration boundary.
